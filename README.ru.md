# 🛡️ WinProxyMon (Монитор прокси и Tor для Windows)

WinProxyMon — это легковесное, ненавязчивое приложение для системного трея Windows (7/8/10/11), предназначенное для мониторинга доступности прокси-серверов. Написанное на Python и PyQt5, оно обеспечивает визуальную обратную связь в реальном времени, умные уведомления и мощный встроенный менеджер для служб Tor.

Запускаете ли вы простой SOCKS5-прокси или сложную систему с Tor-мостами, WinProxyMon гарантирует, что вы всегда знаете точное состояние соединения, не сворачивая игры и не отвлекаясь на всплывающие окна во время работы на весь экран.

> *Авторский коллектив — GLM, GPT.*

## ✨ Основные возможности

* **Мульти-прокси мониторинг:** Одновременный мониторинг неограниченного количества прокси (SOCKS4/5, HTTP, HTTPS).
* **Интеллектуальная 3-уровневая диагностика:** Программа не просто пингует. Она проверяет локальный интернет, доступность порта прокси и фактическую способность пропускать HTTP-трафик.
* **Умное определение полноэкранного режима:** Автоматически подавляет всплывающие уведомления, если запущено приложение на весь экран (например, игра или видеоплеер).
* **Визуальные индикаторы статуса:** Мгновенно видно, работает ли ваш прокси (Зеленый), завис/нет выхода (Желтый) или отключен (Красный).
* **Встроенный менеджер службы Tor:** Специальный графический интерфейс для установки, запуска, остановки и перезапуска службы Tor в Windows.
* **Получение и применение мостов:** Автоматически скачивает свежие `obfs4` мосты с TorProject.org и безопасно записывает их в ваш файл `torrc`.
* **Поддержка автозапуска:** Легкая настройка запуска приложения вместе с Windows.

## 🧠 Как это работает (Логика диагностики)

В отличие от базовых пинг-мониторов, WinProxyMon использует 3-уровневую систему проверок, чтобы дать вам точную картину состояния прокси:

1. **Проверка локального интернета:** Прямое подключение к `8.8.8.8:53`. Если это не удается, на вашем ПК нет локального интернета. Статус: 🔴 **OFFLINE (NO LOCAL NET)**.
2. **Проверка TCP-порта:** Попытка подключения к IP-адресу и порту прокси. Если не удается, значит ПО прокси (например, Tor) не запущено или зависло. Статус: 🔴 **OFFLINE (PORT CLOSED)**.
3. **Проверка HTTP-выхода:** Попытка загрузить сайт через прокси. Если это не удается, но порт открыт, значит прокси запущен, но не может маршрутизировать трафик (например, мосты Tor мертвы). Статус: 🟡 **NO EXIT**.
4. **Успех:** Если HTTP-запрос проходит успешно, прокси полностью работоспособен. Статус: 🟢 **ONLINE**.

Если прокси назначен плагин (например, `tor`), то при возникновении статуса `NO EXIT` приложение запросит у плагина детальные логи ошибок, показав точную причину сбоя загрузки Tor во всплывающей подсказке и лог-файле.

## 🌐 Понимание `check_urls`

В вашем файле `winproxymon.ini` есть настройка `check_urls`. Это список сайтов, разделенных запятыми, которые программа использует для проверки того, может ли трафик успешно выйти через прокси.

**Как выбирать хорошие URL для этого списка:**
1. **Только чистый текст:** URL должен возвращать *только* IP-адрес. Если сайт возвращает HTML, JSON или лишние слова, проверка завершится ошибкой или засорит логи. (Например, `https://api.ipify.org` возвращает просто `185.220.101.5`).
2. **Легковесность:** Используйте быстрые, минимальные API. Избегайте тяжелых веб-страниц с множеством скриптов.
3. **Отсутствие блокировок Cloudflare/Tor:** Многие стандартные сайты блокируют выходные узлы Tor. Значения по умолчанию подобраны так, чтобы быть лояльными к Tor.
4. **Избыточность:** Приложение проверяет их по порядку. Если первый URL недоступен, пробуется следующий. Это предотвращает ложные срабатывания "NO EXIT", если один из сервисов проверки IP упадет.

**Рекомендуемые значения по умолчанию:**
```ini
check_urls = https://api.ipify.org, https://checkip.amazonaws.com, https://ident.me
```

## 🧅 Что такое Tor Expert Bundle?

Если вы просто хотите анонимно серфить в интернете, вы используете **Tor Browser**. Но если вы хотите, чтобы другие приложения (или вся система) маршрутизировали трафик через Tor, вам понадобится **Tor Expert Bundle** (Экспертный пакет Tor).

Tor Expert Bundle — это чистый демон Tor без графического интерфейса. Он работает тихо в фоновом режиме как процесс (или, что лучше, как служба Windows) и открывает SOCKS5-прокси (обычно на `127.0.0.1:9050`).

WinProxyMon создан именно для управления этим пакетом. Он может установить демон Tor как надежную службу Windows, настроить его мосты, читать его логи и мониторить SOCKS5-порт.

## 🚀 Установка и настройка

### Запуск из исходного кода (Python 3.8+)
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/tabookot/winproxymon.git
   cd winproxymon
   ```
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Запустите приложение:
   ```bash
   python winproxymon.py
   ```

### Сборка исполняемого файла (PyInstaller)
Чтобы скомпилировать собственный `.exe`, убедитесь, что установлен PyInstaller, затем используйте предоставленный `.spec` файл, чтобы гарантировать правильную упаковку всех ресурсов и плагинов:
```bash
pyinstaller winproxymon.spec
```
Скомпилированный исполняемый файл будет находиться в папке `dist/`.

## 🛠️ Полное руководство: Настройка Tor с нуля

Выполните следующие шаги, чтобы настроить Tor Expert Bundle как службу Windows, управляемую WinProxyMon.

### Шаг 1: Скачивание Tor Expert Bundle
1. Зайдите на официальную страницу загрузок Tor Project: [Tor Expert Bundle](https://www.torproject.org/download/tor/)
2. Скачайте Windows `.exe` установщик или `.zip` архив.
3. Распакуйте его в постоянную папку, например: `C:\tor\tor\` (Убедитесь, что `tor.exe` находится внутри этой папки).

### Шаг 2: Настройка WinProxyMon
1. Откройте WinProxyMon.
2. Кликните правой кнопкой мыши по иконке в трее и выберите **Manage Proxies...**
3. Нажмите **Add** (или измените прокси по умолчанию).
4. Заполните данные:
   * **Name:** `Tor Local`
   * **Host:** `127.0.0.1` (или ваш LAN IP, если Tor на другом ПК)
   * **Port:** `9050` (Порт Tor SOCKS5 по умолчанию)
   * **Protocol:** `socks5`
   * **Plugin:** Выберите `tor` из выпадающего списка.
5. Нажмите **Save**.

### Шаг 3: Настройка службы Tor через интерфейс плагина
1. В окне Manage Proxies нажмите кнопку **Configure Plugin...**
2. В окне Tor Service Manager:
   * **Раздел 1:** Нажмите `Browse...` и выберите папку с Tor (`C:\tor\tor\`). Приложение автоматически определит пути к `torrc` и `tor.log`.
   * Нажмите **Save Paths to INI**.
3. **Раздел 2 (Мосты):** Если вам нужны мосты:
   * Нажмите **Fetch New Bridges**. Приложение получит `obfs4` мосты с TorProject.org.
   * Нажмите **Apply Paths and Bridges to torrc**. (Автоматически будет создана резервная копия `.bak`).
4. **Раздел 3 (Служба):** 
   * Нажмите **Install**. Приложение запросит права администратора (UAC) для установки Tor как службы Windows.
   * *Примечание: Приложение автоматически выдает системной учетной записи `SYSTEM` полные права на папку Tor, чтобы служба могла писать логи.*

### Шаг 4: Решение проблем со службой Tor
Если служба установилась, но не запускается (Ошибка Windows 1064), обычно это проблема с правами:
1. Нажмите **Open services.msc** в приложении.
2. Найдите службу `tor`, кликните правой кнопкой мыши -> **Свойства**.
3. Перейдите на вкладку **Вход в систему** (Log On).
4. Убедитесь, что выбрана **Системная учетная запись** (Local System account).
5. Вернитесь в WinProxyMon и нажмите **Start**.

## ⚙️ Файл конфигурации (`winproxymon.ini`)

Приложение генерирует INI-файл для хранения настроек. Вы можете редактировать его вручную или через интерфейс.

```ini
[settings]
interval_minutes = 1
ipv6 = false
disable_notifications_in_fullscreen = true
; Список сайтов для проверки HTTP-выхода. Через запятую.
check_urls = https://api.ipify.org, https://checkip.amazonaws.com, https://ident.me

[tor_settings]
torrc_path = C:\tor\tor\torrc
log_path = C:\tor\tor\tor.log
tor_exe_path = C:\tor\tor\tor.exe
service_name = tor

[proxy_1]
name = Tor Local
enabled = true
host = 127.0.0.1
port = 9050
protocol = socks5
username = 
password = 
plugin = tor
```
